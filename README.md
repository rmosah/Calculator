# Simple Calculator

## What is this project?
A simple web calculator built with HTML, CSS, and JavaScript for basic arithmetic (`+`, `-`, `×`, `÷`) with a clean UI and error handling.

## How can it be used?
1. Open `index.html` in any web browser.
2. Click numbers, operators, and `=` to calculate (`⌫` deletes last digit, `C` clears).
